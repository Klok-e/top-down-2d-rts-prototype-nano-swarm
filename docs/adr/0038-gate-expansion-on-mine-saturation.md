# Gate expansion on Mine Saturation

Before adding a mine, the Strategic Controller requires Mine Saturation at each Owned Resource Deposit it plans to keep and a spare crew for the new site. A spare crew has the Worker and Hauler capacity to build the site's support, extract minerals, and deliver its output while meeting existing commitments. This puts Workers to use at existing sites and gives each new site time to start delivering minerals before the controller commits to another.

Normal expansion also requires a sustained mineral supply gap that extra extraction can help close. When the existing supply path is stalled, the controller prioritizes restoring delivery.

Replacing a lost or exhausted mine serves economic recovery. A reachable deposit also qualifies for replacement when sustained evidence shows that its delivery path cannot be restored and a viable replacement is ready.

Mine Saturation requires sustained use of the site's gathering capacity and completed Worker deliveries into its Source Stockpiles. The controller evaluates both over a window so assigned Workers and minerals still in transit cannot satisfy the delivery requirement.

This revises the normal expansion rule in the [persistent deposit economy decision](0029-persistent-deposit-economy.md).
